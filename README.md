# תיק חפיפה - קצין רכב

אתר סטטי לתיק חפיפה לקציני רכב. מאוחסן ב-GitHub Pages.

## קבצים

* `index.html` - האתר (מבנה, עיצוב ולוגיקה)
* `content.js` - כל תוכן הנושאים. כאן מוסיפים/עורכים נושאים.
* `contacts.json` - אנשי קשר לפי נושא ואלמ"ר + רשימת מוסכים. כאן מעדכנים שמות, תפקידים וטלפונים. עדכון במקום אחד מתעדכן בכל הסעיפים באתר אוטומטית.

## פריסה ב-GitHub Pages (פעם אחת)

1. היכנס לחשבון GitHub (yardeny90) וצור מאגר חדש ציבורי, למשל `cars-handover`.
2. העלה את שלושת הקבצים (index.html, content.js, contacts.json) לבראנץ `main`.
3. Settings → Pages → Branch: `main`, תיקייה: `/ (root)` → Save.
4. אחרי דקה האתר יהיה זמין בכתובת: `https://yardeny90.github.io/cars-handover/`

## עדכון תוכן בעתיד

* נושא חדש: הוסף אובייקט למערך `SECTIONS` ב-`content.js` (העתק אובייקט קיים כתבנית).
* איש קשר חדש או החלפת טלפון: ערוך את `contacts.json` בלבד.
* אלמ"ר חדש: הוסף לרשימת `almars` והוסף אנשי קשר תחתיו בנושאים הרלוונטיים.
* מוסך חדש: הוסף למבנה `garages` לפי סוג רכב ואזור.

כל דחיפה ל-`main` מעדכנת את האתר תוך דקה-שתיים.
